# 📊 Social Media Engagement Analytics Using Python

## 📌 Project Overview

The **Social Media Engagement Analytics** project focuses on analyzing social media performance using Python and data analytics techniques. The project explores user engagement metrics to identify trends, audience behavior, and content performance. Through data cleaning, exploratory data analysis (EDA), statistical analysis, and visualization, the project provides actionable insights that can support data-driven marketing decisions.

---

## 🎯 Project Objectives

- Analyze user engagement across different social media post types.
- Identify factors influencing likes, comments, shares, and engagement rates.
- Compare engagement based on user demographics and account characteristics.
- Evaluate the relationship between impressions, watch time, and audience interaction.
- Generate meaningful business insights through data visualization.

## 📊 Key Insights

- Video posts generated the highest engagement among all post types.
- Positive sentiment posts achieved higher engagement compared to neutral and negative posts.
- Verified accounts received significantly more user interactions.
- Engagement varied across different countries and content categories.
- Higher impressions generally resulted in increased likes, comments, and shares.
- Device type influenced watch time and overall engagement behavior.
- Data visualization revealed meaningful trends and user engagement patterns.
